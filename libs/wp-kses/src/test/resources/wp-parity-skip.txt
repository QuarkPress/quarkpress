# Deliberate differences between lib-wp-kses and WordPress 7.1.3; items are the rows of the README's
# "Differences from WordPress" table. Format: <case-id-or-glob> <aspect-or-glob> <item> <reason>.
# "none" documents a difference no oracle case can show. Any other entry whose comparisons all match
# WordPress, or that matches no comparison, fails the build: delete it.
none - #1 invalid UTF-8 cannot reach a Java String; lone surrogates become U+FFFD
ruling-2-* kses #2 WordPress throws a TypeError for a numeric start tag in the entities context; QuarkPress removes the tag
ruling-3-* safecss #3 PCRE's limits make WordPress drop the declaration; QuarkPress keeps it
none - #4 allowed-HTML filters run once per configuration (built-in and registered contexts), not once per tag
none - #5 the protocol list belongs to the Kses instance, not to a static cache frozen after wp_loaded
none - #6 the PDF upload URL is configured (uploadBaseUrl) instead of read from wp_upload_dir()
ruling-7-* kses #7 block attribute keys that become 0..n-1 stay an object; PHP writes a list (a list would no longer read back as block attributes)
ruling-8-template-part-* kses #8 WordPress throws a TypeError for an array or object tagName; QuarkPress writes ""
ruling-8-huge-* * #8 WordPress throws a TypeError for a numeric reference beyond PHP's integer range; QuarkPress decodes it modulo 256
ruling-9-* kses:timeout #9 WordPress never finishes (endless comment recursion in bare mode); QuarkPress drops the comment
gen/soup-*/bare kses:timeout #9 generated bare-mode soups where WordPress never finishes; QuarkPress drops the comment
none - #9 comment recursion is also bounded by depth and a work budget, which can drop comments in very deep legitimate nesting
ruling-10-* kses #10 the block parser's limits are exceeded; QuarkPress neutralizes every block delimiter, WordPress's output is quadratic
ruling-11-* kses #11 block delimiters WordPress leaves live without filtering their attributes are neutralized
gen/soup-*/wp kses:delimiters-neutralized #11 generated soup where the only change is a delimiter WordPress leaves live, neutralized (checked by WpKsesParityTest.onlyDelimitersNeutralized)
ruling-12-* safecss #12 more than 32 url() or gradient removals in one declaration: span removal fails closed and drops it
none - #13 a host pre_kses filter always runs after the default pre-filters; from WordPress's second kses call on, one at priority 10 runs before the block filter
ruling-14-* hair #14 the attribute parser reads an unquoted value past ">" where WordPress stops (unreachable through kses and oneAttr)
